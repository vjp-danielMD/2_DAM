═══════════════════════════════════════════════════════════════════
                        FLUJO DE EJECUCIÓN
═══════════════════════════════════════════════════════════════════

1. Usuario ingresa ID y presiona "Consultar"
   ↓
2. MainActivity captura el evento onClick
   ↓
3. MainActivity llama a DeviceController.obtenerDispositivoPorId(id)
   ↓
4. DeviceController usa ClienteRetrofit.apiService
   ↓
5. APIService realiza petición HTTP GET a la API
   ↓
6. API responde con JSON
   ↓
7. GSON convierte JSON → Device (Modelo)
   ↓
8. DeviceController retorna Device a MainActivity
   ↓
9. MainActivity actualiza la UI con los datos del Device
   ↓
10. Usuario ve los datos en pantalla
