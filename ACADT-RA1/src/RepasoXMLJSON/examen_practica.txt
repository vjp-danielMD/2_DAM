EJERCICIO 1 (3 puntos - mínimo 1.5 puntos):
═══════════════════════════════════════════════════════════════════════════

A partir del fichero peliculas.xml que se proporciona, crea una clase en Java 
llamada Ejercicio1.java y realiza lo siguiente:

1.1) Leer el fichero peliculas.xml usando DOM y mostrar por pantalla ÚNICAMENTE 
     los títulos de las películas que tienen una puntuación mayor o igual a 8.0 
     (1 punto).

1.2) Crear un nuevo fichero XML llamado peliculas_top.xml usando DOM que contenga 
     SOLO las películas con puntuación >= 8.0. El formato debe ser idéntico al 
     original (1 punto).

1.3) Añadir al fichero peliculas_top.xml una nueva película de forma MANUAL 
     (sin crear objetos), con los siguientes datos (1 punto):
     - ID: "P006"
     - Título: "Blade Runner 2049"
     - Director: "Denis Villeneuve"
     - Año: 2017
     - Puntuación: 8.5

EJERCICIO 2 (7 puntos - mínimo 3.5 puntos):
═══════════════════════════════════════════════════════════════════════════

A partir del fichero videojuegos.xml crea una clase en Java llamada Ejercicio2.java 
y un modelo de clases para su deserialización. Realiza un programa que contenga 
un menú con las siguientes opciones:

OPCIÓN 1: Deserializar y cargar en memoria el fichero videojuegos.xml mediante 
          XStream (1.5 puntos).
          - Mostrar por pantalla todos los videojuegos cargados.

OPCIÓN 2: Una vez cargado el XML, partiendo de los datos que están en memoria, 
          crea un nuevo XML llamado catalogo.xml utilizando DOM (1.5 puntos), 
          con las siguientes modificaciones:
          
          - Añade un nuevo videojuego de forma MANUAL (sin añadir objeto a la lista):
            * Título: "Elden Ring"
            * Plataforma: "PC"
            * Precio: 59.99
            (0.5 puntos)

          NOTA: Si no eres capaz de cargar el XML, créate los objetos en memoria 
                desde el programa para probar la creación del nuevo fichero.

OPCIÓN 3: Guarda el contenido original del fichero XML en un nuevo fichero JSON 
          llamado catalogo.json (1.5 puntos) utilizando JsonWriter, con algunas 
          modificaciones:
          
          - Añade el mismo videojuego nuevo de forma MANUAL (sin añadir objeto):
            * Título: "Elden Ring"
            * Plataforma: "PC"
            * Precio: 59.99
            (0.5 puntos)

          NOTA: No es necesario procesar de nuevo el fichero, ya que lo tenemos 
                cargado en memoria. Sí que es conveniente realizar esta comprobación.

OPCIÓN 4: Procesa el fichero JSON cargando su información en memoria y mostrando 
          el contenido por pantalla para comprobar que se ha generado correctamente 
          (1.25 puntos).
          
          - Muestra el contenido de una manera "amigable" o "pretty" (0.25 puntos).

OPCIÓN 0: Salir del programa.

NOTAS IMPORTANTES:
═══════════════════════════════════════════════════════════════════════════

1. Los ficheros XML proporcionados deben crearse antes de ejecutar el programa.

2. En el Ejercicio 2, es obligatorio:
   - Comprobar que los datos están cargados en memoria antes de ejecutar las 
     opciones 2, 3 y 4.
   - Usar una variable estática para mantener los datos en memoria entre opciones.

3. "Añadir de forma MANUAL" significa que NO puedes crear un nuevo objeto y 
   añadirlo a la lista. Debes escribir los elementos directamente en el fichero 
   usando los métodos createElement(), createTextNode(), beginObject(), etc.

4. El menú debe funcionar en bucle hasta que se seleccione la opción de salir.

5. Se valorará:
   - Código limpio y bien estructurado
   - Manejo correcto de excepciones
   - Mensajes informativos al usuario
   - Formato correcto de los ficheros generados
